# PDF → Markdown 변환 도구 사용법

한국 교육문서(법령, 교육과정, 업무계획 등) PDF를 구조화된 Markdown으로 변환하는 도구입니다.

## 설치

```bash
pip install pdfminer.six
```

## 사용법

### 단일 파일 변환

```bash
python pdf_to_md.py 파일.pdf
```

PDF와 같은 폴더에 `파일.md`가 생성됩니다.

### 폴더 전체 변환

```bash
python pdf_to_md.py 폴더경로/
```

하위 폴더 포함 모든 PDF를 변환합니다.

### 출력 폴더 지정

```bash
python pdf_to_md.py 폴더경로/ --out 결과폴더/
```

### 이미 변환된 파일 건너뛰기

```bash
python pdf_to_md.py 폴더경로/ --skip-existing
```

### 예시

```bash
# 교육법 폴더 전체 변환
python pdf_to_md.py "C:\Users\NT940XGQ\Desktop\교육법\"

# 교육과정 폴더 변환 (이미 있는 파일 제외)
python pdf_to_md.py "C:\Users\NT940XGQ\Desktop\교육과정\" --skip-existing

# 특정 파일만
python pdf_to_md.py "D:\Hwan\Documents\Web\byeduin-edu-docs\실무지침\2026 학교생활기록부 기재요령(초).pdf"
```

## 변환 규칙

| PDF 원문 | Markdown 변환 |
|----------|--------------|
| 법 제목 (단독 줄) | `# 제목` (H1) |
| 제X장 | `## 제X장` (H2) |
| 제X절 | `### 제X절` (H3) |
| 제X조 | `#### 제X조` (H4) |
| 1. 2. 3. (번호 항목) | `## 1.` (H2) |
| 가. 나. 다. | `### 가.` (H3) |
| (1) (2) (3) | `#### (1)` (H4) |
| ① ② ③ | `- ① …` (목록) |
| ○ • ▸ (불릿) | `- …` (목록) |
| [시행 …] [법률 …] | `> [시행 …]` (인용) |
| ※ 참고사항 | `> ※ …` (인용) |
| 페이지 번호 (`- 1 -`) | 제거 |
| 법제처/국가법령정보센터 푸터 | 제거 |

## 한계

- **이미지 기반 PDF** (스캔본): 텍스트 추출 불가. OCR 도구(예: tesseract) 별도 필요.
- **표(Table)**: 현재 일반 텍스트로 추출됨. 복잡한 표는 수동 수정 필요.
- **줄 끊김**: PDF 단(column) 레이아웃에 따라 일부 문장이 잘못 합쳐질 수 있음.

## 파일 구조

```
pdf-to-md/
├── pdf_to_md.py   # 변환 프로그램
└── 작업방법.md     # 이 파일
```
